OPCIÓN A

Descarga e instalación local

Todas las descargas están en el repositorio principal de la app.

github.com/thatsme4now/btc-tracking Código fuente, releases, README con todas las variantes de instalación
Abrir repositorio ↗

Variante 1 — JAR (requiere Java)

Requisito: Java 21+ instalado.

  1. En el repositorio, ve a Releases (barra lateral derecha en GitHub) y descarga el último btc-tracking.jar.
  2. Abre una terminal en la carpeta de descarga.
  3. Inicia la app: 
    java -jar btc-tracking.jar
  4. El navegador se abre automáticamente en http://localhost:8080/btc-tracking. Los datos se guardan por defecto en btc-tracking-data.mv.db junto al JAR (H2, persistente) — haz copia de seguridad de este archivo para conservar tus datos.

Variante 2 — ZIP portable para Windows (sin Java)

Incluye una JRE integrada — no requiere una instalación de Java independiente.

  1. En el repositorio, descarga el ZIP para Windows en Releases (incluye JRE integrada + lanzador).
  2. Descomprime el ZIP por completo (no solo lo abras — la JRE también debe extraerse).
  3. En la carpeta descomprimida, ejecuta BtcTracking.exe (o el script de inicio .bat).
  4. El servidor arranca localmente en el puerto 8080, el navegador se abre automáticamente en http://localhost:8080/btc-tracking.
ℹ Nota: Los detalles de otras variantes de instalación (en memoria sin persistencia, conexión a MySQL, compilación desde el código fuente con ./gradlew bootJar) están en el README del repositorio.
OPCIÓN B

Instalación en Umbrel

La app también se puede instalar como app en un nodo Umbrel — a través de una Community App Store propia, sin necesidad de estar incluida en la Umbrel App Store oficial.

github.com/thatsme4now/thatsme4now-umbrel-apps Community App Store · incluye la app «thatsme4now-btc-tracking»
Abrir repositorio ↗
  1. En la interfaz de umbrelOS, ve a la App Store y abre la sección de Community App Stores (ahí se pueden añadir URLs de tiendas externas).
  2. Introduce la URL: 
    https://github.com/thatsme4now/thatsme4now-umbrel-apps
  3. Añade la tienda — Umbrel carga las apps incluidas en el repositorio.
  4. Selecciona la app «BTC Tracking» de esta Community Store e instálala como cualquier otra app de Umbrel.
  5. Tras la instalación, la app es accesible desde el panel de Umbrel, los datos permanecen persistentes en el nodo Umbrel.
ℹ Nota: Las Community App Stores son una función habitual de Umbrel para apps fuera de la tienda oficial. Las rutas exactas del menú pueden variar ligeramente según la versión de umbrelOS.
OPCIÓN C

Instalación con Docker

La app también está disponible como imagen Docker — se ejecuta de forma aislada, sin instalación local de Java.

hub.docker.com/r/thatsme4now/btc-tracking Imagen Docker de la app
Abrir Docker Hub ↗

Requisito: Docker instalado (p. ej. Docker Desktop en Windows).

  1. Abre una terminal o PowerShell.
  2. Inicia el contenedor: 
    docker run -d \
  --name btc-tracking \
  -p 8080:8080 \
  -v btc-tracking-data:/app/data \
  thatsme4now/btc-tracking:latest
  3. Abre la app en el navegador en http://localhost:8080/btc-tracking.
ℹ Persistencia: El volumen con nombre btc-tracking-data conserva los datos entre reinicios y actualizaciones de la imagen. Para actualizar basta con docker pull thatsme4now/btc-tracking:latest seguido de un reinicio del contenedor — el volumen se conserva.
OPCIÓN D

Instalación con Proxmox

No hay una plantilla dedicada de Proxmox — se ejecuta mediante una VM o contenedor LXC normal en el nodo Proxmox con Docker instalado. A partir de ahí se aplican los mismos pasos que en la Opción C.

  1. En el nodo Proxmox, crea una VM o un LXC (privilegiado o no privilegiado), p. ej. con Debian/Ubuntu.
  2. Instala Docker dentro de la VM/LXC.
  3. Ejecuta el comando docker run de la Opción C dentro de la VM/LXC.
  4. Accede a la app por la IP de la VM/LXC: http://<IP-VM>:8080/btc-tracking.
ℹ Nota: Para LXC se necesita Docker anidado (virtualización anidada) — actívalo en Proxmox mediante Features → Nesting en el contenedor antes de instalar Docker.
