₿ Bitcoin Portfolio — Guide

Guide rapide des fonctions principales de l'app BTC-Tracking : import CSV via l'assistant en 3 étapes, gestion des transactions et positions dans Gestion des données, et export CSV. Importer un CSV

Sélectionnez un fichier via « Importer CSV ». L'import se déroule comme un assistant en trois étapes : Correspondance, Vérification et Statut.

1. Correspondance

L'app détecte automatiquement les colonnes et propose une correspondance — par exemple pour les exports CoinTracking, les formats d'export de portefeuille, ou vos propres fichiers avec des noms de colonnes différents. Un aperçu en direct montre immédiatement comment les lignes détectées seront interprétées.

  • Champs obligatoires (avec *) : Type, Date, Portefeuilles & Exchanges, Montant d'achat, Devise d'achat, Montant de vente, Devise de vente doivent chacun être associés à une colonne CSV.
  • Portefeuille / Exchange fixe : remplace la correspondance de colonnes et fixe la même position pour toutes les lignes — utile pour les fichiers qui ne couvrent qu'un seul exchange. Si aucun exchange n'est associé, la zone est mise en surbrillance.
  • Correspondance des valeurs de type : chaque valeur distincte présente dans le fichier (p. ex. Retrait, Staking) est associée à un type interne précis — ou définie sur – ignorer – pour exclure ces lignes de l'import.

2. Vérification

Chaque ligne détectée est vérifiée individuellement avant l'import proprement dit. Les lignes en couleur indiquent où une vérification est utile — p. ex. doublons possibles ou valeurs invalides. La sélection multiple permet de confirmer, corriger ou exclure des lignes de cet import en bloc.

3. Statut

Résumé de l'import : combien de lignes ont été importées, ignorées ou détectées comme doublons. De là, vous revenez à Gestion des données, où les transactions importées sont immédiatement visibles.

ℹ Astuce : Avant l'import définitif, vérifiez à l'étape Correspondance le nombre de lignes détectées — s'il ne correspond pas au fichier source, vérifiez si le séparateur ou la ligne d'en-tête ont été correctement détectés.

Format CSV personnalisé

Sans l'option CoinTracking, l'app exporte dans son propre format. C'est aussi le format attendu par un import CSV manuel sans mappage automatique CoinTracking. 

"typ","date","exchange","buyQty","buyCur","sellQty","sellCur","fee","feeCur","comment"
"Dépôt","20.07.2026 16:53:27","Bitbox02","0.00490000","BTC","","","","EUR","Example transfer to own wallet"
"Retrait","20.07.2026 16:53:26","21 Bitcoin","","","0.00500000","BTC","0.00010000","BTC","Example transfer to own wallet"
"Trade","19.07.2026 16:53:26","21 Bitcoin","0.01000000","BTC","500.00","EUR","0.00000000","EUR","Example transaction"

Important : typ détermine le type d'opération (Dépôt / Retrait / Trade), buyQty/buyCur et sellQty/sellCur décrivent respectivement ce qui a été acheté et vendu.

ℹ Détection flexible : La correspondance de l'étape 1 reconnaît aussi des noms de colonnes différents provenant d'autres formats d'export (p. ex. Time, Unit, Fee Unit, Transaction ID, Note), les montants en satoshi sont convertis automatiquement en BTC, et les dates avec un décalage horaire (p. ex. 2026-07-20T16:53:27-03:00) sont correctement interprétées.

Gestion des données

Les positions et transactions se gèrent sur la page « Gestion des données ». Les cartes peuvent être réorganisées par glisser-déposer via la poignée et repliées/dépliées — l'ordre est enregistré.

Portefeuilles & Exchanges

Tableau de toutes les positions. Utilisez « Ajouter portefeuille / exchange » pour créer une nouvelle position — chaque exchange/portefeuille doit être créé une fois avant la première opération. Cliquer sur une ligne filtre la liste des transactions sur cette position ; un filtre masque les positions sans solde.

Toutes les transactions

Liste complète de toutes les opérations. « Ajouter une transaction » ouvre un formulaire pour une seule opération :

Marquage des lignes par couleur

La couleur de fond d'une ligne dans la liste des transactions indique automatiquement l'un des quatre états suivants :

CouleurSignification
🟠 OrangeDevise étrangère sans taux de change — transaction dans une devise différente de la devise d'affichage, le taux de change est encore à 1. À corriger via « Définir le taux de change ».
🟣 VioletDoublon possible — la date, le type et le montant correspondent à une transaction déjà existante. Vérifier et confirmer via « Pas un doublon », ou supprimer la ligne.
🔵 BleuTransfert isolé — dépôt ou retrait sans opération de contrepartie sur une autre position, volontairement marqué comme opération individuelle.
🔴 Rouge foncéImporté récemment — la ligne provient de l'import CSV de la session en cours, pour une vérification rapide après l'import.

La légende directement au-dessus du tableau affiche les mêmes quatre couleurs pour référence rapide.

Historique des imports

Carte listant tous les imports CSV précédents : date, nom de fichier, nombre total de lignes et combien ont été importées, détectées comme doublons ou en erreur. Les imports individuels peuvent être supprimés depuis ici.

ℹ Indicateurs & graphiques : la performance, le solde, la répartition et le gain/perte par achat ne sont plus affichés ici, mais dans la Vue du Portefeuille.

Verrouiller l'app

L'icône de cadenas dans l'en-tête (à côté de « Actions » / « Visualisation ») chiffre toutes les positions et transactions avec un mot de passe et supprime les données en clair de la base de données. Utile si l'app reste sans surveillance ou si la machine sous-jacente n'est pas totalement fiable.

ChampSignification
Mot de passeMot de passe de chiffrement — requis pour déverrouiller ultérieurement
Confirmer le mot de passeDoit correspondre exactement, sinon le verrouillage est refusé
ℹ Ce qui se passe lors du verrouillage : Toutes les positions et transactions sont chiffrées avec le mot de passe et supprimées de la base de données. L'app affiche ensuite à chaque visite une boîte de dialogue bloquante « App verrouillée » jusqu'à ce que le bon mot de passe soit saisi de nouveau — ce qui restaure aussi les données. Les tentatives erronées sont freinées par un délai croissant.
🔒 Chiffrement : AES-256-GCM, la clé est dérivée du mot de passe via PBKDF2WithHmacSHA256 avec 310 000 itérations et un sel aléatoire de 16 octets. Chaque chiffrement utilise un nonce GCM aléatoire de 12 octets ; le tag d'authentification 128 bits détecte, au déverrouillage, un mot de passe erroné ou des données altérées.
⚠ Important : Il n'existe aucune récupération de mot de passe. En cas de perte du mot de passe, les données chiffrées ne peuvent pas être restaurées.

Déverrouiller

Quand l'app est verrouillée, la boîte de dialogue « App verrouillée » avec un champ de mot de passe s'affiche à chaque visite. Après saisie du bon mot de passe, les données sont déchiffrées et restaurées.

♻ Mot de passe perdu : Utilisez Réinitialiser l'application dans la boîte de dialogue de déverrouillage pour réinitialiser l'app si le mot de passe n'est plus connu. Cela supprime irréversiblement toutes les données chiffrées et l'app redémarre comme une nouvelle installation. La confirmation nécessite de saisir DELETE.

Autres fonctions

La barre d'icônes à droite de l'en-tête regroupe les paramètres globaux et les outils disponibles sur toutes les pages.

Paramètres

L'icône d'engrenage ouvre la boîte de dialogue des paramètres :

ChampSignification
LangueLangue de l'interface de l'app
Devise d'affichageDevise fiat pour toutes les valeurs calculées (solde, gain/perte, …)
PoliceFixée sur Inconsolata et non modifiable tant que le Mode Einundzwanzig est actif
Date butoir fiscale (fin de l'exonération)Pour les pièces achetées à partir de cette date, l'exonération fiscale après 1 an ne s'applique plus. Laisser vide pour désactiver. Informatif uniquement, pas un conseil fiscal.

Cours du BTC

L'affichage du cours à gauche de l'en-tête peut être écrasé manuellement en cliquant sur la valeur — pratique quand aucun cours actuel ne peut être chargé.

Mode hors ligne

L'icône Wi-Fi active ou désactive le mode hors ligne. Tant qu'il est actif, l'app ne récupère pas automatiquement les cours depuis internet — le cours peut toujours être défini manuellement. Le réglage est enregistré localement dans le navigateur.

Menu Actions : sauvegarde & réinitialisation

Outre l'import/export CSV, le menu « Actions » contient une sauvegarde complète de la base de données, indépendante de l'export CSV :

ActionSignification
Exporter BDSauvegarde les positions, transactions, l'historique des imports et toutes les données de cours (quotidiennes, mensuelles et annuelles) au format JSON. Mot de passe optionnel — laisser vide pour un fichier non chiffré.
Importer BDSupprime TOUTES les positions, transactions, l'historique des imports et les données de cours actuelles, et les remplace par la sauvegarde restaurée. Ne peut pas être annulé.
⚠ Attention avec « Tout supprimer » : Cette entrée du menu Actions supprime immédiatement toutes les données après une simple confirmation — contrairement à la réinitialisation dans la boîte de dialogue « App verrouillée » (voir étape 04), qui exige de saisir le mot delete pour confirmer. Il est conseillé de faire d'abord une sauvegarde.
07 / 07

Mode Einundzwanzig

L'icône « 21 » dans l'en-tête active un thème de couleurs alternatif avec sa propre police (Inconsolata) et un bandeau défilant reprenant des citations de la culture Bitcoiner. Tant que le mode est actif, le bouton normal clair/sombre et le sélecteur de police dans les Paramètres sont verrouillés.

₿ Nommé d'après le podcast Bitcoin germanophone einundzwanzig.space et inspiré par lui (« einundzwanzig » signifie « vingt et un » en allemand).
