₿ Bitcoin Portfolio — Utilisation & Installation

Deux façons d'exécuter l'app : téléchargement manuel (JAR ou ZIP portable Windows) ou installation en tant qu'app sur Umbrel via la Community App Store.

OPTION A

Téléchargement & installation locale

Tous les téléchargements se trouvent dans le dépôt principal de l'app.

github.com/thatsme4now/btc-tracking Code source, releases, README avec toutes les variantes d'installation
Ouvrir le dépôt ↗

Variante 1 — JAR (Java requis)

Prérequis : Java 21+ installé.

  1. Dans le dépôt, aller dans Releases (barre latérale droite sur GitHub) et télécharger le dernier btc-tracking.jar.
  2. Ouvrir un terminal dans le dossier de téléchargement.
  3. Démarrer l'app : 
    java -jar btc-tracking.jar
  4. Le navigateur s'ouvre automatiquement sur http://localhost:8080/btc-tracking. Les données sont stockées par défaut dans btc-tracking-data.mv.db à côté du JAR (H2, persistant) — sauvegardez ce fichier pour conserver vos données.

Variante 2 — ZIP portable pour Windows (sans Java)

Inclut un JRE intégré — aucune installation Java séparée n'est nécessaire.

  1. Dans le dépôt, télécharger le ZIP Windows sous Releases (inclut le JRE intégré + le lanceur).
  2. Décompresser entièrement le ZIP (ne pas juste l'ouvrir — le JRE doit aussi être extrait).
  3. Dans le dossier décompressé, exécuter BtcTracking.exe (ou le script de démarrage .bat).
  4. Le serveur démarre localement sur le port 8080, le navigateur s'ouvre automatiquement sur http://localhost:8080/btc-tracking.
ℹ Remarque : Les détails sur d'autres variantes d'installation (en mémoire sans persistance, connexion MySQL, compilation depuis les sources avec ./gradlew bootJar) figurent dans le README du dépôt.
OPTION B

Installation sur Umbrel

L'app peut aussi être installée en tant qu'app sur un nœud Umbrel — via une Community App Store dédiée, sans avoir besoin d'être listée dans la Umbrel App Store officielle.

github.com/thatsme4now/thatsme4now-umbrel-apps Community App Store · contient l'app « thatsme4now-btc-tracking »
Ouvrir le dépôt ↗
  1. Dans l'interface umbrelOS, aller dans l'App Store et ouvrir la section Community App Stores (c'est là que des URL de boutiques externes peuvent être ajoutées).
  2. Saisir l'URL : 
    https://github.com/thatsme4now/thatsme4now-umbrel-apps
  3. Ajouter la boutique — Umbrel charge les apps contenues dans le dépôt.
  4. Sélectionner l'app « BTC Tracking » dans cette Community Store et l'installer comme n'importe quelle autre app Umbrel.
  5. Après l'installation, l'app est accessible via le tableau de bord Umbrel, les données restent persistantes sur le nœud Umbrel.
ℹ Remarque : Les Community App Stores sont une fonctionnalité standard d'Umbrel pour les apps en dehors de la boutique officielle. Les chemins de menu exacts peuvent légèrement varier selon la version d'umbrelOS.
OPTION C

Installation via Docker

L'app est également disponible en image Docker — s'exécute de manière isolée, sans installation Java locale.

hub.docker.com/r/thatsme4now/btc-tracking Image Docker de l'app
Ouvrir Docker Hub ↗

Prérequis : Docker installé (p. ex. Docker Desktop sous Windows).

  1. Ouvrir un terminal ou PowerShell.
  2. Démarrer le conteneur : 
    docker run -d \
  --name btc-tracking \
  -p 8080:8080 \
  -v btc-tracking-data:/app/data \
  thatsme4now/btc-tracking:latest
  3. Ouvrir l'app dans le navigateur à http://localhost:8080/btc-tracking.
ℹ Persistance : Le volume nommé btc-tracking-data conserve les données lors des redémarrages et des mises à jour d'image. Pour une mise à jour, docker pull thatsme4now/btc-tracking:latest suivi d'un redémarrage du conteneur suffit — le volume est conservé.
OPTION D

Installation via Proxmox

Il n'existe pas de template Proxmox dédié — l'exécution se fait via une VM ou un conteneur LXC classique sur le nœud Proxmox, avec Docker installé. Ensuite, les mêmes étapes que l' Option C s'appliquent.

  1. Sur le nœud Proxmox, créer une VM ou un LXC (privilégié ou non privilégié), p. ex. avec Debian/Ubuntu.
  2. Installer Docker dans la VM/LXC.
  3. Exécuter la commande docker run de l'Option C dans la VM/LXC.
  4. Accéder à l'app via l'IP de la VM/LXC : http://<IP-VM>:8080/btc-tracking.
ℹ Remarque : Pour LXC, Docker imbriqué (virtualisation imbriquée) est nécessaire — activez-le dans Proxmox via Features → Nesting sur le conteneur avant d'installer Docker.
