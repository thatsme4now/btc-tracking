OPTION A

ดาวน์โหลดและติดตั้งแบบโลคัล

ไฟล์ดาวน์โหลดทั้งหมดอยู่ใน repository หลักของแอป

github.com/thatsme4now/btc-tracking ซอร์สโค้ด รีลีส README ที่มีรายละเอียดการติดตั้งทุกรูปแบบ
เปิด Repository ↗

รูปแบบที่ 1 — JAR (ต้องมี Java)

สิ่งที่ต้องมี: ติดตั้ง Java 21+

  1. ใน repository ไปที่ Releases (แถบด้านขวาบน GitHub) แล้วดาวน์โหลด btc-tracking.jar เวอร์ชันล่าสุด
  2. เปิด terminal ในโฟลเดอร์ที่ดาวน์โหลดไฟล์ไว้
  3. เริ่มการทำงานของแอป: 
    java -jar btc-tracking.jar
  4. เบราว์เซอร์จะเปิดขึ้นเองที่ http://localhost:8080/btc-tracking ข้อมูลจะถูกบันทึกไว้ที่ btc-tracking-data.mv.db ในโฟลเดอร์เดียวกับ JAR โดยค่าเริ่มต้น (H2 แบบถาวร) — สำรองไฟล์นี้ไว้เพื่อรักษาข้อมูลของคุณ

รูปแบบที่ 2 — Windows ZIP แบบพกพา (ไม่ต้องใช้ Java)

มี JRE รวมมาให้แล้ว — ไม่ต้องติดตั้ง Java แยกต่างหาก

  1. ใน repository ดาวน์โหลด ZIP สำหรับ Windows ใต้ Releases (มี JRE รวมมาให้พร้อมตัวเปิดโปรแกรม)
  2. แตกไฟล์ ZIP ให้หมด (อย่าเพียงแค่เปิดดู — ต้องแตกไฟล์ JRE ออกมาด้วย)
  3. ในโฟลเดอร์ที่แตกไฟล์แล้ว ให้รัน BtcTracking.exe (หรือสคริปต์เริ่มต้น .bat)
  4. เซิร์ฟเวอร์จะเริ่มทำงานบนพอร์ต 8080 เบราว์เซอร์จะเปิดขึ้นเองที่ http://localhost:8080/btc-tracking
ℹ หมายเหตุ: รายละเอียดการติดตั้งรูปแบบอื่น ๆ (แบบ in-memory ไม่บันทึกข้อมูล เชื่อมต่อ MySQL หรือ build จากซอร์สโค้ดด้วย ./gradlew bootJar) อยู่ใน README ของ repository
OPTION B

ติดตั้งบน Umbrel

แอปนี้สามารถติดตั้งเป็นแอปบนโหนด Umbrel ได้เช่นกัน — ผ่าน Community App Store ของตัวเอง โดยไม่จำเป็นต้องอยู่ใน Umbrel App Store อย่างเป็นทางการ

github.com/thatsme4now/thatsme4now-umbrel-apps Community App Store · มีแอป「thatsme4now-btc-tracking」
เปิด Repository ↗
  1. ในหน้าจอ umbrelOS ไปที่ App Store และเปิดส่วน Community App Stores (จุดที่สามารถเพิ่ม URL ของสโตร์ภายนอกได้)
  2. ป้อน URL นี้: 
    https://github.com/thatsme4now/thatsme4now-umbrel-apps
  3. เพิ่มสโตร์ — Umbrel จะโหลดแอปที่อยู่ใน repository นี้
  4. เลือกแอป 「BTC Tracking」 จาก Community Store นี้และติดตั้งเหมือนแอป Umbrel อื่น ๆ
  5. หลังติดตั้งเสร็จ จะเข้าถึงแอปได้ผ่านแดชบอร์ดของ Umbrel ข้อมูลจะยังคงอยู่บนโหนด Umbrel
ℹ หมายเหตุ: Community App Store เป็นฟีเจอร์ปกติของ Umbrel สำหรับแอปนอกสโตร์อย่างเป็นทางการ เส้นทางเมนูที่แน่นอนอาจแตกต่างกันเล็กน้อยตามเวอร์ชันของ umbrelOS
OPTION C

ติดตั้งผ่าน Docker

แอปนี้ยังมี Docker image ให้ใช้งาน — ทำงานแยกอิสระ โดยไม่ต้องติดตั้ง Java บนเครื่อง

hub.docker.com/r/thatsme4now/btc-tracking Docker image ของแอป
เปิด Docker Hub ↗

สิ่งที่ต้องมี: ติดตั้ง Docker (เช่น Docker Desktop บน Windows)

  1. เปิด terminal หรือ PowerShell
  2. เริ่มคอนเทนเนอร์: 
    docker run -d \
  --name btc-tracking \
  -p 8080:8080 \
  -v btc-tracking-data:/app/data \
  thatsme4now/btc-tracking:latest
  3. เปิดแอปในเบราว์เซอร์ที่ http://localhost:8080/btc-tracking
ℹ ความคงอยู่ของข้อมูล: named volume ชื่อ btc-tracking-data จะรักษาข้อมูลไว้แม้รีสตาร์ทหรืออัปเดต image เมื่อต้องการอัปเดต เพียงรัน docker pull thatsme4now/btc-tracking:latest แล้วรีสตาร์ทคอนเทนเนอร์ — volume จะยังคงอยู่
OPTION D

ติดตั้งผ่าน Proxmox

ไม่มีเทมเพลต Proxmox โดยเฉพาะ — ใช้งานผ่าน VM หรือคอนเทนเนอร์ LXC ทั่วไปบนโหนด Proxmox ที่ติดตั้ง Docker ไว้แล้ว จากนั้นทำตามขั้นตอนเดียวกับ ตัวเลือก C

  1. บนโหนด Proxmox สร้าง VM หรือ LXC (แบบมีสิทธิ์พิเศษหรือไม่มี) เช่น ด้วย Debian/Ubuntu
  2. ติดตั้ง Docker ใน VM/LXC นั้น
  3. รันคำสั่ง docker run จากตัวเลือก C ใน VM/LXC
  4. เข้าถึงแอปผ่าน IP ของ VM/LXC: http://<VM-IP>:8080/btc-tracking
ℹ หมายเหตุ: สำหรับ LXC จำเป็นต้องเปิดใช้ Nested Docker (Nested Virtualization) — เปิดใน Proxmox ผ่าน Features → Nesting ที่คอนเทนเนอร์ก่อนติดตั้ง Docker

รูปแบบสิ่งที่ต้องมีเหมาะสำหรับ
JARติดตั้ง Java 21+Linux/Mac/Windows สำหรับผู้ที่ใช้ Java อยู่แล้ว
Windows ZIP แบบพกพาไม่ต้องมี — มี JRE รวมมาให้Windows ที่ไม่ได้ติดตั้ง Java

Dockerติดตั้ง Docker (เช่น Docker Desktop บน Windows)ทำงานแยกอิสระโดยไม่ต้องติดตั้ง Java บนเครื่อง อัปเดตง่ายด้วยการ pull image
Proxmoxโหนด Proxmox, VM/LXC ที่มี Dockerใช้งานต่อเนื่องบนโครงสร้างพื้นฐาน Proxmox ของตัวเอง
