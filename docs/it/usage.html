OPZIONE A

Download e installazione locale

Tutti i download si trovano nel repository principale dell'app.

github.com/thatsme4now/btc-tracking Codice sorgente, release, README con tutte le varianti di installazione
Apri repository ↗

Variante 1 — JAR (richiede Java)

Requisito: Java 21+ installato.

  1. Nel repository, vai su Releases (barra laterale destra su GitHub) e scarica l'ultimo btc-tracking.jar.
  2. Apri un terminale nella cartella di download.
  3. Avvia l'app: 
    java -jar btc-tracking.jar
  4. Il browser si apre automaticamente su http://localhost:8080/btc-tracking. I dati vengono salvati di default in btc-tracking-data.mv.db accanto al JAR (H2, persistente) — esegui il backup di questo file per conservare i tuoi dati.

Variante 2 — ZIP portatile per Windows (senza Java)

Include una JRE integrata — non richiede un'installazione Java separata.

  1. Nel repository, scarica lo ZIP per Windows sotto Releases (include JRE integrata + launcher).
  2. Estrai completamente lo ZIP (non limitarti ad aprirlo — anche la JRE deve essere estratta).
  3. Nella cartella estratta, esegui BtcTracking.exe (o lo script di avvio .bat).
  4. Il server si avvia localmente sulla porta 8080, il browser si apre automaticamente su http://localhost:8080/btc-tracking.
ℹ Nota: I dettagli su altre varianti di installazione (in memoria senza persistenza, connessione MySQL, build dal codice sorgente con ./gradlew bootJar) sono nel README del repository.
OPZIONE B

Installazione su Umbrel

L'app può essere installata anche come app su un nodo Umbrel — tramite una Community App Store dedicata, senza bisogno di essere inclusa nella Umbrel App Store ufficiale.

github.com/thatsme4now/thatsme4now-umbrel-apps Community App Store · include l'app «thatsme4now-btc-tracking»
Apri repository ↗
  1. Nell'interfaccia umbrelOS, vai nell'App Store e apri la sezione Community App Stores (lì si possono aggiungere URL di store esterni).
  2. Inserisci l'URL: 
    https://github.com/thatsme4now/thatsme4now-umbrel-apps
  3. Aggiungi lo store — Umbrel carica le app contenute nel repository.
  4. Seleziona l'app «BTC Tracking» da questo Community Store e installala come qualsiasi altra app Umbrel.
  5. Dopo l'installazione, l'app è raggiungibile dal pannello Umbrel, i dati restano persistenti sul nodo Umbrel.
ℹ Nota: I Community App Store sono una funzione normale di Umbrel per app al di fuori dello store ufficiale. I percorsi esatti dei menu possono variare leggermente a seconda della versione di umbrelOS.
OPZIONE C

Installazione con Docker

L'app è disponibile anche come immagine Docker — funziona in modo isolato, senza installazione Java locale.

hub.docker.com/r/thatsme4now/btc-tracking Immagine Docker dell'app
Apri Docker Hub ↗

Requisito: Docker installato (ad es. Docker Desktop su Windows).

  1. Apri un terminale o PowerShell.
  2. Avvia il container: 
    docker run -d \
  --name btc-tracking \
  -p 8080:8080 \
  -v btc-tracking-data:/app/data \
  thatsme4now/btc-tracking:latest
  3. Apri l'app nel browser su http://localhost:8080/btc-tracking.
ℹ Persistenza: Il volume denominato btc-tracking-data mantiene i dati tra riavvii e aggiornamenti dell'immagine. Per un aggiornamento basta docker pull thatsme4now/btc-tracking:latest seguito da un riavvio del container — il volume viene mantenuto.
OPZIONE D

Installazione con Proxmox

Non esiste un template Proxmox dedicato — si utilizza una normale VM o container LXC sul nodo Proxmox con Docker installato. Da lì valgono gli stessi passaggi dell'Opzione C.

  1. Sul nodo Proxmox, crea una VM o un LXC (privilegiato o non privilegiato), ad es. con Debian/Ubuntu.
  2. Installa Docker nella VM/LXC.
  3. Esegui il comando docker run dell'Opzione C nella VM/LXC.
  4. Raggiungi l'app tramite l'IP della VM/LXC: http://<IP-VM>:8080/btc-tracking.
ℹ Nota: Per LXC è necessario Docker annidato (virtualizzazione annidata) — attivalo in Proxmox tramite Features → Nesting sul container prima di installare Docker.
