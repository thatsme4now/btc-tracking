VISUALISIERUNG 01

Fluss-Diagramm (Sankey)

Aufrufbar im Dashboard-Header über „Visualisierung“ → „Fluss-Diagramm“ (oder direkt unter /btc-tracking/flow). Es zeichnet ein Sankey-Diagramm davon, wie sich die eigenen BTC über die Zeit bewegt haben: Käufe fließen von links hinein, Verkäufe und externe Auszahlungen fließen nach rechts hinaus, und Transfers zwischen eigenen Wallets/Börsen erscheinen als Verbindungen zwischen den Positions-Knoten. Buchungen werden pro Monat und pro Quelle/Ziel-Paar gebündelt, damit das Diagramm auch bei langer Historie lesbar bleibt.

Filter

FilterWirkung
Von / BisDiagramm auf einen Zeitraum einschränken
PositionDiagramm auf eine Wallet/Börse verankern — verfolgt deren BTC rückwärts (Herkunft) und vorwärts (Ziel)

Farblegende

  • Kauf — BTC in eine Position gekauft
  • Verkauf — BTC aus einer Position verkauft
  • Transfer — zwischen zwei eigenen Positionen bewegt
  • Extern — Einzahlung von bzw. Auszahlung an eine Adresse außerhalb der erfassten Positionen

Transaktions-Panel

Neben dem Diagramm zeigt ein Panel jede zugrunde liegende Buchung als Card (Datum, Position, Typ, BTC-Menge, Preis, Gebühren, Währung, Wechselkurs, Transfer-ID, Kommentar). Kauf, Verkauf sowie Transfer-Ein- und -Ausgang bekommen jeweils ein kleines farbiges Badge. Ein Suchfeld über der Liste filtert nach jedem auf den Cards sichtbaren Wert (Position, Typ, Datum, Beträge, Kommentar, …) — unabhängig davon, ob Beträge mit Punkt oder Komma eingegeben werden. Auf schmaleren Bildschirmen rutscht das Panel unter das Diagramm statt daneben zu stehen.

Interaktion im Diagramm

AktionErgebnis
Node oder Link hovernTooltip mit exakter Menge, Monat, Positions-Bestand und der Liste der einzelnen Buchungen dahinter
Node oder Link anklickenHebt ihn hervor und filtert das Transaktions-Panel auf nur die zugehörigen Buchungen; der Panel-Titel wechselt auf „Gefiltert: …“ mit Button zum Zurücksetzen. Erneuter Klick auf dasselbe Element setzt zurück, Klick auf ein anderes wechselt sofort um.

Interaktion im Transaktions-Panel

AktionErgebnis
Transaktions-Card hovernTemporäre Vorschau-Hervorhebung des passenden Links/der Nodes im Diagramm (nur solange keine Diagramm-Auswahl aktiv ist)
Transaktions-Card anklickenPinnt die Hervorhebung für genau diese Buchung im Diagramm — ohne die Liste zu filtern oder zu verkleinern, und ohne Panel-Titel/Zähler zu ändern. Erneuter Klick auf dieselbe Card entfernt das Pinning, Klick auf eine andere Card wechselt die Hervorhebung sofort um.
ℹ Warum zwei unterschiedliche Klick-Verhalten? Ein Klick direkt im Diagramm dient zum Eingrenzen („zeig mir nur, was zu diesem Node/Link gehört“). Ein Klick auf eine bereits sichtbare Card in der Liste dient dem schnellen visuellen Nachschlagen („wo im Diagramm ist diese eine Buchung?“), ohne die Position in der vollständigen Liste zu verlieren.
