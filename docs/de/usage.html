₿ Bitcoin Portfolio — Nutzung & Setup

Zwei Wege, die App zu betreiben: manueller Download (JAR oder portables Windows-ZIP) oder Installation als App auf Umbrel über den Community App Store.

Download & lokale Installation

Variante 1 — JAR (Java erforderlich)

Voraussetzung: Java 21+ installiert.

  1. Im Repository auf Releases gehen (rechte Seitenleiste auf GitHub) und die neueste btc-tracking.jar herunterladen.
  2. Terminal im Download-Ordner öffnen.
  3. App starten: 
    java -jar btc-tracking.jar
  4. Browser öffnet automatisch http://localhost:8080/btc-tracking. Daten werden standardmäßig in btc-tracking-data.mv.db neben der JAR gespeichert (H2, dauerhaft) — diese Datei sichern, um Daten zu behalten.

Variante 2 — Portables ZIP für Windows (kein Java nötig)

Enthält eine gebündelte JRE — keine separate Java-Installation erforderlich.

  1. Im Repository unter Releases das ZIP für Windows herunterladen (enthält gebündelte JRE + Launcher).
  2. ZIP vollständig entpacken (nicht nur öffnen — die JRE muss mit extrahiert werden).
  3. Im entpackten Ordner die BtcTracking.exe (bzw. das .bat-Startskript) ausführen.
  4. Server startet lokal auf Port 8080, Browser öffnet automatisch http://localhost:8080/btc-tracking.
ℹ Hinweis: Details zu weiteren Setup-Varianten (In-Memory ohne Persistenz, MySQL-Anbindung, Build aus dem Quellcode mit ./gradlew bootJar) stehen im README des Repositories.
OPTION B

Installation auf Umbrel

Die App lässt sich auch als App auf einer Umbrel-Node installieren — über einen eigenen Community App Store, keine Aufnahme im offiziellen Umbrel App Store nötig.

github.com/thatsme4now/thatsme4now-umbrel-apps Community App Store · enthält die App „thatsme4now-btc-tracking“
Repository öffnen ↗
  1. In der umbrelOS-Oberfläche zum App Store gehen und den Bereich für Community App Stores öffnen (dort können externe Store-URLs hinzugefügt werden).
  2. Als URL eintragen: 
    https://github.com/thatsme4now/thatsme4now-umbrel-apps
  3. Store hinzufügen — Umbrel lädt die enthaltenen Apps aus dem Repository.
  4. Die App „BTC Tracking“ aus diesem Community Store auswählen und wie jede andere Umbrel-App installieren.
  5. Nach der Installation ist die App über das Umbrel-Dashboard erreichbar, Daten bleiben persistent auf der Umbrel-Node.
ℹ Hinweis: Community App Stores sind eine reguläre Umbrel-Funktion für Apps außerhalb des offiziellen Stores. Genaue Menüpfade können sich je nach umbrelOS-Version leicht unterscheiden.
